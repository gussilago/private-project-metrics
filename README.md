## Counting rules

Statistics use physical tracked lines from the private repository.

- Application code includes tracked C#, Razor, CSS, JavaScript and TypeScript source.
- Test code is measured separately from application code.
- Documentation counts tracked Markdown lines.
- Automated tests count declared test methods.
- Generated files, dependencies, vendored content and build output are excluded.

Only aggregate values are published. No source files, file names, internal structure or private repository metadata are exposed here.
